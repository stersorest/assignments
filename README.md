# Basic Python Programs

## Description

This repository contains basic Python programs created to practice and understand fundamental programming concepts.

## Programs

### Q1: Sum of first N natural numbers

* Calculates the sum from 1 to N

### Q2: Multiplication table

* Prints multiplication table of a given number

### Q3: Factorial of a number

* Computes factorial using iteration

### Q4: Count digits in a number

* Counts total number of digits in an integer

## Concepts Used

* Loops (while loop)
* Conditional statements
* Arithmetic operations
* Number manipulation

## How to Run

1. Open the program file
2. Run using Python
3. Enter input when prompted
